# 글로벌 길일 앱

앱을 열면 바로 오늘의 운세가 뜨는 개인 맞춤 운세 앱입니다. 한국의 사주·토정비결, 일본의 일립만배일·육요, 중국 황력, 서양 점성술 등 전 세계의 운세를 한데 모아 재물·합격·연애 같은 분야별 점수와 근거로 보여줍니다.

## 주요 기능

- **오늘의 운세 (첫 화면)**: 종합 점수(0~100), 한 줄 요약, 분야별 점수, 행운의 색·숫자·방위
- **기간 버튼**: 오늘 · 내일 · 이번 주 · 이번 달 · 올해 운세와 기간 안의 좋은 날 TOP 3
- **분야별 상세**: 나라별 근거 카드 (예: 사주 편재일 +2, 일본 일립만배일 +1, 수성 역행 −1)
- **복권·합격 카드**: 복권 사기 좋은 날과 로또 명당, 서류 내기·면접 좋은 날
- **내 사주·토정비결·궁합**, 캘린더, 알림, 공유 카드, 위젯

## 맞춤 단계

| 단계 | 입력 | 보이는 것 |
| --- | --- | --- |
| 기본 | 없음 | 모두에게 같은 날의 길흉 |
| 개인 | 생년월일, 성별 | 사주 세 기둥, 띠·별자리 등 개인 운세 |
| 완전 맞춤 | 생년월일 + 태어난 시간 | 사주 전체, 대운, 좋은 시간대 (향후 구독 상품) |

출시 때는 모든 기능을 무료로 제공하고, 이후 완전 맞춤을 구독으로 전환할 계획입니다.
